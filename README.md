# Code Sample – The Effect of Natural Disasters on Child and Early Marriage in Bangladesh

This repository contains one of the code scripts from my forthcoming paper titled  
**“The Effect of Natural Disasters on Child and Early Marriage in Bangladesh:  A Logistic and Cox Proportional Hazards Regression Analysis of the 2019 MICS.”**

This paper, finalized and ready for journal submission, examines child marriage as a coping mechanism in disaster-prone areas using the **MICS 2019 dataset** and the **INFORM Hazard Index 2022**. The analysis employs **logistic regression** and **Cox proportional hazards models** to estimate the effects of disaster exposure on child and early marriage outcomes.

> **Note:** This repository includes only one of the analytical code scripts from the full study, provided as a sample for evaluation purposes.
